# КарточкаPRO

ИИ-сервис, который за 10 секунд пишет продающие SEO-карточки для Wildberries и Ozon: название, описание, ключевые слова, преимущества и тексты для инфографики.

## Запуск

```bash
node server.js                                   # демо-режим (шаблоны, без ИИ)
ANTHROPIC_API_KEY=sk-ant-... node server.js      # настоящий ИИ
```

Откройте http://localhost:3000

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `ANTHROPIC_API_KEY` | ключ с console.anthropic.com | — (демо-режим) |
| `MODEL` | модель | `claude-sonnet-5-5` |
| `FREE_PER_DAY` | бесплатных генераций в день на IP | 3 |
| `PAYMENT_URL` | ссылка на оплату (ЮKassa / Prodamus / Boosty) | `#` |
| `PRO_CODES` | PRO-коды для оплативших, через запятую | — |

## Бизнес-план

**Проблема.** Продавцам на WB и Ozon нужны десятки и сотни карточек. Копирайтер берёт 300–1000 ₽ за одну и пишет её 1–2 дня. Плохая карточка означает, что товар не находят в поиске.

**Решение.** Готовая SEO-карточка за 10 секунд по цене меньше одного текста у копирайтера.

**Монетизация.**
- Старт: 0 ₽, 3 карточки в день (бесплатный уровень для привлечения пользователей)
- PRO: 490 ₽/мес, безлимит
- Агентство: 1 990 ₽/мес, команда и массовая загрузка

**Экономика.** Одна генерация стоит примерно 0,5–1,5 ₽ на API. Активный PRO-пользователь делает около 100 карточек в месяц, это примерно 100 ₽ себестоимости. Маржа около 80%.

**Цель.** 200 PRO-подписчиков дают ≈ 98 000 ₽/мес.

## План запуска (4 недели)

1. **Неделя 1: деплой.** Арендовать VPS (Timeweb / Selectel, ~300 ₽/мес) или Render/Railway, купить домен, получить API-ключ.
2. **Неделя 1: оплата.** Оформить самозанятость, подключить Prodamus или ЮKassa, вставить ссылку в `PAYMENT_URL`. После оплаты выдавать PRO-код, пока вручную.
3. **Неделя 2: первые пользователи.** Telegram-чаты селлеров WB/Ozon (их десятки, с аудиторией от 10 до 100 тыс.), форумы, VC.ru. Дать бесплатный PRO на месяц первым 50 пользователям в обмен на отзыв.
4. **Неделя 3: контент.** Ролики в TikTok, YouTube Shorts и Reels в формате «карточка за 10 секунд: до и после».
5. **Неделя 4: партнёрка.** 30% с каждой оплаты для блогеров и курсов по маркетплейсам.
